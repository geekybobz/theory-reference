# Box Usage

Use only when they add information density.

- `roadmap`: once per chapter
- `keyidea`: central conceptual insight
- `keyeqn`: only for core equations
- `intuition`: useful mental model
- `mistake`: real common misconception only
- `checkpoint`: local verification step
- `refnote`: once per section, at end
- `selfcheck`: when a claim is fully proved here
- `connection`: once near chapter end
- `notation`: only for notation-heavy openings

Rules:
- No nested boxes
- At most 2 boxes per section
- Bullets only inside `roadmap`
