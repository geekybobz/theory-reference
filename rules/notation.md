# Notation Conventions

These apply to all documents generated by this skill. Domain-specific additions go in the preamble's DOMAIN MACROS block.

---

## General conventions

| Object | Convention | Example |
|---|---|---|
| Scalars | lowercase italic | $x$, $\alpha$, $\gamma$ |
| Vectors | bold lowercase | $\mathbf{x}$, $\mathbf{w}$ |
| Matrices | bold uppercase | $\mathbf{A}$, $\mathbf{P}$ |
| Random variables | uppercase | $X$, $S$, $A$, $R$ |
| Sets | calligraphic | $\mathcal{X}$, $\mathcal{H}$, $\mathcal{S}$ |
| Distributions | $P$, $\mathcal{D}$, $\mu$ | $P(s' \mid s, a)$ |
| Functions / maps | lowercase or named | $f$, $\pi$, $V$, $Q$ |
| Operators | upright | $\mathrm{tr}$, $\mathrm{diag}$, $\argmax$ |
| Indices | subscript | $s_t$, $a_t$, $r_{t+1}$ |
| Parameters | $\theta$, $\phi$, $w$ | $\pi_\theta$, $Q_\phi$ |

---

## Expectation notation

Always specify the distribution when non-obvious:
- $\mathbb{E}_{x \sim P}[f(x)]$ when the distribution matters
- $\mathbb{E}_\pi[\cdot]$ shorthand when the policy is clear from context
- $\mathbb{E}[X]$ only when the distribution is unambiguous

---

## Probability and information

- Probability: $P(\cdot)$ or $p(\cdot)$ (uppercase for distributions, lowercase for densities)
- KL divergence: $\KL{p}{q} = \mathbb{E}_p[\log(p/q)]$
- Shannon entropy: $\mathcal{H}(p) = -\mathbb{E}_p[\log p]$ (note: $\mathcal{H}$ not $H$ to avoid conflict with Hamiltonian)

---

## Asymptotic and approximation

- Big-O: $O(\cdot)$
- Approximately equal: $\approx$
- Defined as: $:=$ (left side is being defined)
- Proportional to: $\propto$
