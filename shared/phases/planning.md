# Planning Phase

## Goal

Produce a compact plan for a theoretical reference before any LaTeX is written.

## Research

Find:
- canonical textbooks
- strong lecture notes
- influential surveys or tutorials

Extract:
- standard concept order
- notation conventions
- assumed prerequisites
- common misconceptions
- proof style
- examples that build intuition

## Output to user

Present:
- 3 to 5 best sources, one line each
- 2 to 3 pedagogy options
- recommended pedagogy for a personal study reference
- chapter order with dependency notes

Ask for approval before proceeding.

## After approval

Read `outline_format.md`.

Write to PROJECT_DIR:
- `{PROJECT_DIR}/plan.md`
- `{PROJECT_DIR}/outline/ch{NN}.md` for each chapter (zero-padded: `ch01`, `ch02`, …)

Keep each outline dense and short.
Do not generate LaTeX in this phase.
